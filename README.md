# Bank-Loan-Analytics
Bank Loan Data Analysis using Excel, MySQL, Power BI and Tableau

🏦 Bank Loan Analytics

📊 Project Overview

This project focuses on analyzing bank loan data, customer behavior, loan performance, repayment patterns, and financial trends using multiple data analytics tools.

The project transforms raw financial data into meaningful insights through data cleaning, SQL analysis, KPI development, and interactive dashboards.

🛠️ Tools & Technologies

* Microsoft Excel
* MySQL
* Power BI
* Tableau

📈 Key Analysis Performed

* Year-wise Loan Amount Analysis
* Grade & Sub-Grade Revolving Balance Analysis
* Verified vs. Non-Verified Payments Analysis
* State-wise Loan Status Analysis
* Home Ownership Analysis
* Last Payment Date Analysis
* Loan Portfolio Performance Analysis
* Customer & Repayment Pattern Analysis
